Module A — Round Trough Wedge

Module B — Rectangular Linear Strip
For Hynds rectangular / oblong troughs, both long sides
Top View
Cross-Section B–B
Trough fit: Rectangular, any length (chain multiple units) Module size: 600 × 600mm per unit, stackable end-to-end Structure: Honeycomb infill base (40% density, PLA) Channels: Perpendicular to trough edge, 5 per module Sensor: Optional color-change N indicator dot (top surface)
Module C — Corner Connector (L-piece)
Joins Module B strips at rectangular trough corners
Top View
Cross-Section
Shape: L-piece, 600 × 600mm arms Connects: Module B strips at 90° corners Extra structure: Diagonal ribs at corner junction (higher stress zone) Channels: Both arms + diagonal corner drain to outer edge
Module D — Universal Ground Tile
Portable troughs / high-traffic areas / any freeform layout
Top View — Tiles connect freely
Cross-Section
Size: 300 × 300mm per tile (smaller, lighter, stackable) Connects: Snap connectors on all 4 edges — arrange any shape Thickness: 30mm (thinner — portable, low ground clearance) Structure: Grid rib base + anti-slip surface bumps Use case: Portable troughs, irregular areas, trial installations
Load-Bearing Analysis
Dairy cow weight: 450–650 kg
Per hoof (4 hooves): ~160 kg
Hoof contact area: ~150 cm²
Pressure: ~1.1 kg/cm²
PLA compressive strength: ~50 MPa
Rib structure factor of safety: > 8×
→ Ribbed/honeycomb PLA easily handles cow load

Clip system: All modules use the same male/female quarter-turn connector on edges — one standardised clip across all 4 types. Modules A/B/C/D are all interoperable at their straight edges.  |  Drainage: All channels slope outward at 2° — liquid drains to outer edge, collected by a perimeter lip into soil or a drainage strip.  |  Replacement: Each module lifts out individually. Saturated biochar layer is replaceable without replacing the structural shell (two-part design: shell + biochar cartridge).
