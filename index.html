System layers: hardware / IoT / GIS
Cows don't care where they urinate — but Canterbury's groundwater does.
CowPad is a modular trough-side system that captures urinary nitrogen in replaceable biochar cartridges, uses an EC sensor to detect saturation, and returns spent cartridges as slow-release fertiliser — passively, without power, without service visits.
